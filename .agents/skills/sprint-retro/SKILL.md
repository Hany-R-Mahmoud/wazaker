# Sprint Retro

## Purpose

Generate an end-of-sprint summary that explains outcomes, misses, and carryover.

## Responsibilities

- summarize completed versus incomplete work
- call out visible blockers and carryover themes
- estimate lightweight delivery trends from the sprint snapshot
- produce a founder-readable retrospective artifact
