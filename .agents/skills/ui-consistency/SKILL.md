# UI Consistency

## Purpose

Audit UI changes against the current mobile design language and accessibility expectations.

## Responsibilities

- inspect changed UI files or the current app shell
- flag interaction, token, and layout inconsistencies
- identify missing accessibility affordances
- write a focused audit report for follow-up
