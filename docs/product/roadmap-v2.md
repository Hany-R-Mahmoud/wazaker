# Roadmap V2

## Execution Order

1. Clear human gates for infrastructure, API access, and Quran data access.
2. Stand up the VPS runtime with `n8n`, OpenClaw, self-hosted Supabase, and Whisper.cpp.
3. Import Quran content, reference audio metadata, and timing data.
4. Upgrade the automation stack for the target runtime.
5. Refactor the mobile app into the Phase 1 learner journey.
6. Ship the real scoring path as part of Phase 1.
7. Add Phase 2 memorization and progress features after Phase 1 is stable.

## Phase 1

- authentication
- home dashboard
- Surah browser
- Mushaf reader
- reference audio playback
- ayah recording
- confidence-aware scoring
- session history

## Phase 2

- memorization mode
- goals and streaks
- progress trends
- mistake history
